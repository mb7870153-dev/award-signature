# Информационная система «Электронное подписание наградных документов»

## Назначение системы

Информационная система предназначена для организации процесса подготовки,
согласования и электронного подписания наградных документов.

## Участники процесса

- Предприятие — подаёт заявку на награждение и отслеживает её статус.
- Сотрудник сектора — проверяет заявку и направляет её на согласование.
- Член комиссии — рассматривает заявку.
- Мэр — подписывает итоговый документ с использованием УКЭП.
- СМЭВ — обеспечивает передачу подписанного документа во внешнюю систему.

## Основной процесс работы

1. Предприятие подаёт заявку на награждение.
2. Сотрудник сектора проверяет заявку.
3. Заявка направляется на рассмотрение комиссии.
4. Член комиссии рассматривает заявку.
5. После согласования документ передаётся на подписание.
6. Мэр подписывает документ с использованием УКЭП.
7. Документ передаётся через СМЭВ.
8. Документ переводится в архив.

## Разрабатываемая функция

В рамках текущей версии разрабатывается функция подачи заявки
на награждение и отслеживания её текущего статуса.

## Структура проекта

На следующих этапах лабораторной работы будут сформированы версии системы,
ветки разработки и исправлений, а также документация проекта.
