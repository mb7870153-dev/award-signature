# Информационная система «Электронное подписание наградных документов»

## Назначение системы

Информационная система предназначена для автоматизации процесса подачи, рассмотрения, согласования и электронного подписания наградных документов.

## Основные возможности

* подача заявки на награду;
* загрузка необходимых документов;
* отслеживание статуса заявки;
* проверка документов сотрудником сектора;
* рассмотрение заявок членами комиссии;
* электронное подписание документов с использованием УКЭП;
* формирование отчетов;
* передача подписанных документов через СМЭВ.

## Основные пользователи

* предприятие;
* сотрудник сектора по наградам;
* член комиссии;
* мэр;
* внешняя система СМЭВ.

## GitFlow

В проекте используются следующие основные ветки:

* `master` — стабильная версия проекта;
* `develop` — основная ветка разработки;
* `feature/*` — разработка отдельных функций;
* `release/*` — подготовка версии к выпуску;
* `hotfix/*` — исправление ошибок в стабильной версии.
## Версия 1.0.0

Первая версия системы включает базовый сценарий обработки наградного документа:

- подачу заявки предприятием;
- проверку заявки сотрудником сектора;
- рассмотрение заявки членом комиссии;
- подготовку документа к подписанию;
- электронное подписание с использованием УКЭП;
- передачу подписанного документа через СМЭВ;
- отслеживание состояния заявки.
* База данных системы реализована в СУБД MS SQL Server.
## Реализация MVP
Минимально жизнеспособный продукт (MVP) реализован в среде Visual Studio на языке C# (Windows Forms). Клиентское приложение обеспечивает операции управления данными для 6 таблиц БД: организации, типы наград, статусы, сотрудники, наградные представления и документы.
