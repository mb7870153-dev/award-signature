# Дизайн и прототип интерфейса

В этой папке хранятся макеты пользовательского интерфейса информационной системы «Электронное подписание наградных документов», разработанные в Figma.

## Содержимое

- `ui-kit.png` — дизайн-система (цвета, шрифты, компоненты)
- `screen-login.png` — экран «Вход в систему»
- `screen-registry.png` — экран «Реестр заявок»
- `screen-card.png` — экран «Карточка наградного представления»
- `screen-documents.png` — экран «Документы и приложения»
- `screen-route.png` — экран «Маршрут согласования»
- `screen-signing.png` — экран «Подписание документа»
