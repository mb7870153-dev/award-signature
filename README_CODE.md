# Демонстрационный модуль обработки наградных заявок

## Назначение

Модуль `src/award_application.py` демонстрирует часть логики информационной системы
«Электронное подписание наградных документов»: проверку обязательных полей заявки
и контроль последовательности её статусов.

## Статусы

Черновик → Подана → На проверке → Одобрена / Отклонена.
При необходимости заявка может быть возвращена на доработку и подана повторно.
После одобрения предусмотрены статусы «Подписана», «Передана» и «Архивирована».

## Запуск тестов локально

Установите зависимости командой:

```bash
python -m pip install -r requirements.txt
```

Запустите тесты:

```bash
python -m pytest -v
```

## Автоматическое тестирование на GitHub

Файл `.github/workflows/python-tests.yml` настраивает GitHub Actions. Тесты
автоматически запускаются при отправке изменений (`push`) в ветки `master` и
`develop`, а также при создании Pull Request с целевой веткой `master` или
`develop`.

Workflow проверяет проект на Python 3.9 и 3.12, устанавливает зависимости из
`requirements.txt` и запускает `pytest -v`. Результат проверки отображается во
вкладке Actions репозитория GitHub.

## Ограничения демонстрации

Программа только фиксирует статусы «Подписана» и «Передана». Она не реализует
криптографическую УКЭП, не отправляет документы в СМЭВ и не заменяет реальную
информационную систему.
